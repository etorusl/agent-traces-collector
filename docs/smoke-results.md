# Проверочный прогон Gemma 4 12B

29 октября 2026 года. Это smoke-проверка сборщика на 3 задачах каждого бенчмарка, а не оценка качества на полном наборе. Тексты задач, вложения и трассы в Git не публикуются.

## Условия

- Endpoint: `http://everest.nsu.ru:9022/v1`; сервер сообщает `gemma-4-12B-it`, vLLM `0.29.0`, context `60000`, fingerprint `vllm-0.29.0-0a92be7d`. SHA весов и quantization endpoint не раскрывает.
- Код эксперимента: `4299576d3477524d94f2e5388a5f7fd5a1fbb762`.
- AppWorld `0.1.3`, данные `0.1.0`, split `dev`. Выбраны первые 3 задания официального порядка (один сценарий).
- GAIA `2023/validation`, snapshot `682dd723ee1e1697e00360edccf2366dc8418dd9`; загружены 165 заданий, выбраны первые 3.
- Профиль Gemma: нативные действия, `assistant.reasoning` + `assistant.tool_calls` + `role=tool`; `enable_thinking=true`, `preserve_thinking=true`.
- `temperature=1.0`, `top_p=0.95`, `top_k=64`, seed `42`; максимум 4096 токенов на ответ, 20000 на задачу, 30 шагов, 600 секунд работы агента.
- Прогоны двух бенчмарков последовательные. GAIA без поискового провайдера и без vision/audio-инструментов; прямой HTTP fetch доступен.

## Проверки

- Проверены 74 реальных ответа: число output IDs совпадает с server completion usage; `generated = reasoning + response + reasoning_overhead`.
- Reasoning считается по реальным token IDs между проверенными маркерами Gemma, без пересчёта текста. Подставленные в prompt маркеры не начисляются как generated tokens.
- Для всех 6 попыток usage и reasoning полные, предупреждений учёта нет. Нет потерянных/in-flight LLM-запросов.
- 65 автоматических тестов прошли, включая настоящий AppWorld engine/evaluator и сквозной CLI через локальный HTTP.
- Поля predictor features проверены: только `user_request`. Ключей из локального `.env` в артефактах не обнаружено.
- Resume повторно проверяет сервер и пропускает завершённые попытки, без новых генераций.
