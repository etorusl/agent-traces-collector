# Профили совместимости

Профиль выбирается явно через `model.family`; автоматического определения по
подстроке имени модели нет. Это небольшие адаптеры конкретных семейств,
а не универсальный агентный framework.

| Семейство | Конфигурации | Протокол | Статус |
| --- | --- | --- | --- |
| Gemma 4 | `gemma-appworld.toml`, `gemma-gaia.toml` | Нативные tool calls, reasoning внутри tool-turn, обычный финальный текст и output token IDs | Проверен на настоящем gemma-4-12B-it: по 3 задачи AppWorld/GAIA |
| Qwen3 | `appworld.toml`, `gaia.toml` | JSON-действия, reasoning/reasoning_content или think-теги | Подготовлен; реальный endpoint ещё не проверен |
| JSON | `model.family="json"` | Строгий JSON с tool/arguments или final_answer | Только базовый протокол для совместимых моделей |

Новые семейства добавляются по реальным ответам сервера: отдельный промпт,
разбор действий, маркеры/счётчики и тесты наблюдённых вариантов. Настройки одной
модели не переносятся молча на другую. Смена профиля создаёт новый эксперимент.
